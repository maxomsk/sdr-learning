# Обучение ИИ и МЛ — курсы и готовые материалы

Подборка для тех, кто **уже умеет программировать** и имеет **инженерное образование**:
минимум «воды», максимум практики, математика даётся в объёме, необходимом инженеру.
Охват — и общий ML/DL, и узкое направление **МЛ для радио/SDR/сигналов (RFML)**,
в русле задач этого репозитория. Обновлено: 2026-10-19.

Условные пометки: 🟢 бесплатно · 🟡 бесплатно с платным сертификатом/продлением · 🔵 платно.

## 5. МЛ для радио / SDR / сигналов (RFML)

Специфика направления: входные данные — IQ-потоки и спектрограммы, а не картинки/текст;
нужна связка DSP + ML.

| Ресурс | Что даёт | Ссылка |
|---|---|---|
| 🟢 PySDR — A Guide to SDR and DSP using Python | база SDR/цифровой обработки сигналов на Python | https://pysdr.org/ |
| 🟢 GNU Radio — Tutorials | классическая среда SDR, бесплатные уроки | https://wiki.gnuradio.org/index.php/Tutorials |
| 🟢 TorchSig (DeepSig) | открытый тулкит RFML: модели, датасеты, аугментация сигналов | https://torchsig.com/ · https://github.com/torchsig/torchsig |
| 🟢 RadioML 2016.10a / 2018.01a (DeepSig) | эталонные датасеты модуляций для классификации сигналов | https://www.deepsig.ai/datasets/ |
| 🟢 Sionna (NVIDIA) | библиотека link-level моделирования для ML в беспроводных системах | https://nvlabs.github.io/sionna/ |
| 🟢 torchaudio (PyTorch) | мост audio↔RF: спектрограммы, аугментация, классификация | https://pytorch.org/audio/ |
| 🟢 O'Shea & Hoydis — «An Introduction to Deep Learning for the Physical Layer» (arXiv) | вводная статья DL для радиоканала | https://arxiv.org/abs/1702.00832 |
| 🟢 DeepSig — публикации и блог по RFML | обзоры и результаты по классификации сигналов | https://www.deepsig.ai/ |
| 🟢 Обзор «AI in Software-Defined Radio: A Survey» (IEEE Access, 2026) | уже в репозитории, переведён | `translate/переводы2005/Artificial_Intelligence_in_SDR_A_Survey_ru.docx` |

## Рекомендуемый маршрут (2 трека)

**Трек A — общий ML/DL (2–3 месяца):**
1. 3Blue1Brown (линал + нейросети) → книга Mathematics for ML — 1–2 недели.
2. Andrew Ng ML Specialization **или** Google ML Crash Course — 3–4 недели.
3. fast.ai Part 1 **или** Karpathy Zero-to-Hero — практика на PyTorch — 4–6 недель.
4. Dive into Deep Learning (d2l.ai) как справочник + Kaggle для закрепления.

**Трек B — RFML для SDR (после/параллельно с A):**
1. PySDR + GNU Radio Tutorials — база DSP/SDR.
2. O'Shea & Hoydis (статья) — как DL применяется к физическому уровню.
3. TorchSig + RadioML 2018.01a — классификация модуляций из коробки.
4. Разбор датасетов этого репозитория (RFUAV/CageDroneRF) и переводов в `translate/`.

**Если нужно быстро на практике:** fast.ai (трек A) → PySDR + TorchSig (трек B).
