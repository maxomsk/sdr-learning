13.6 Набор данных для обнаружения объектов

Для обнаружения объектов нет таких небольших наборов данных, как MNIST или Fashion-MNIST. Чтобы быстро проверить модели обнаружения, мы соберём и разметим небольшой набор данных. Сначала мы сфотографировали бананы и получили 1000 изображений бананов под разными углами и разных размеров. Затем мы поместили изображения бананов в случайные места фоновых изображений. Наконец, на этих изображениях мы разметили ограничивающие рамки бананов.

13.6.1 Загрузка набора данных

Набор данных для обнаружения бананов, содержащий все изображения и CSV-файл с метками, можно загрузить напрямую из интернета.

13.6.2 Чтение набора данных

С помощью функции read_data_bananas мы читаем набор данных для обнаружения бананов. Набор включает CSV-файл с метками классов и координатами левого верхнего и правого нижнего углов истинных ограничивающих рамок.

MXNet:

#@save
def read_data_bananas(is_train=True):
    """Читает изображения и метки из набора данных для обнаружения бананов"""
    data_dir = d2l.download_extract('banana-detection')
    csv_fname = os.path.join(data_dir, 'bananas_train' if is_train
                             else 'bananas_val', 'label.csv')
    csv_data = pd.read_csv(csv_fname)
    csv_data = csv_data.set_index('img_name')
    images, targets = [], []
    for img_name, target in csv_data.iterrows():
        images.append(image.imread(
            os.path.join(data_dir, 'bananas_train' if is_train else
                         'bananas_val', 'images', f'{img_name}')))
        # Здесь target содержит (класс, x левого верхнего, y левого верхнего, x правого нижнего, y правого нижнего),
        # причём все изображения имеют один и тот же класс «банан» (индекс 0)
        targets.append(list(target))
    return images, np.expand_dims(np.array(targets), 1) / 256

Используя функцию read_data_bananas для чтения изображений и меток, класс BananasDataset ниже позволяет создать собственный экземпляр Dataset для загрузки набора данных для обнаружения бананов.

MXNet:

#@save
class BananasDataset(gluon.data.Dataset):
    """Пользовательский набор данных для загрузки набора для обнаружения бананов"""
    def __init__(self, is_train):
        self.features, self.labels = read_data_bananas(is_train)
        print('прочитано ' + str(len(self.features)) + (f' обучающих примеров' if
              is_train else f' проверочных примеров'))

    def __getitem__(self, idx):
        return (self.features[idx].astype('float32').transpose(2, 0, 1),
                self.labels[idx])

    def __len__(self):
        return len(self.features)

Наконец, определим функцию load_data_bananas, которая возвращает два экземпляра загрузчика данных для обучающего и тестового наборов. Для тестового набора не нужно читать данные в случайном порядке.

MXNet:

#@save
def load_data_bananas(batch_size):
    """Загружает набор данных для обнаружения бананов"""
    train_iter = gluon.data.DataLoader(BananasDataset(is_train=True),
                                       batch_size, shuffle=True)
    val_iter = gluon.data.DataLoader(BananasDataset(is_train=False),
                                     batch_size)
    return train_iter, val_iter

Прочитаем один минибатч и выведем формы изображений и меток. Форма минибатча изображений — (размер батча, число каналов, высота, ширина), как и в задачах классификации изображений. Форма минибатча меток — (размер батча, m, 5), где m — максимальное число ограничивающих рамок, которое может встретиться на изображении набора данных.

Вычисления на минибатчах эффективны, но требуют, чтобы у всех изображений в одном батче было одинаковое число ограничивающих рамок. Обычно число рамок у изображений разное, поэтому изображения с числом рамок меньше m дополняются фиктивными (недопустимыми) рамками до m. Тогда метка каждой рамки представлена массивом длины 5. Первый элемент массива — класс объекта в рамке, где -1 означает фиктивную (недопустимую) рамку, добавленную для дополнения. Остальные четыре элемента — координаты (x,y) левого верхнего и правого нижнего углов рамки (значения от 0 до 1). В наборе данных о бананах на каждом изображении ровно одна рамка, поэтому m=1.

13.6.3 Демонстрация

Покажем 10 изображений с истинными ограничивающими рамками. Видно, что на всех этих изображениях бананы повёрнуты по-разному, имеют разный размер и расположены в разных местах. Разумеется, это простой искусственный набор данных; реальные наборы данных на практике обычно гораздо сложнее.

Резюме

  • Собранный нами набор данных для обнаружения бананов можно использовать для демонстрации моделей обнаружения объектов.
  • Загрузка данных для обнаружения объектов похожа на загрузку данных для классификации изображений. Однако в обнаружении объектов метки также содержат информацию об истинных ограничивающих рамках, которой нет в классификации изображений.
