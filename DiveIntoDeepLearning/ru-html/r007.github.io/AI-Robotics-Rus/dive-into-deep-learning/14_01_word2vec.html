Погружение в глубокое обучение

14.1 Вложения слов (word2vec)

Естественный язык — сложная система, с помощью которой выражают мысли. В этой системе слово — основная единица смысла. Как следует из названия, векторы слов — это векторы, представляющие значение слов; их можно также считать векторами признаков или представлениями слов. Технику отображения слов в вещественные векторы называют вложением слов (word embedding). В последние годы вложения слов постепенно стали базовым знанием в обработке естественного языка.

14.1.1 Почему one-hot-векторы — плохой выбор

В разделе 8.5 мы использовали one-hot-векторы для представления слов (слова там были символами). Пусть число различных слов в словаре (размер словаря) равно N, а каждому слову соответствует своё целое число (индекс) от 0 до N−1. Чтобы получить one-hot-вектор слова с индексом i, мы создаём вектор длины N, состоящий из нулей, и ставим 1 в позицию i. Так каждое слово представляется вектором длины N, который можно сразу подавать в нейронную сеть.

Хотя one-hot-векторы легко строить, обычно они — плохой выбор. Главная причина в том, что one-hot-векторы не могут точно выразить сходство между разными словами, например часто используемое нами «косинусное сходство». Для векторов x,y∈Rd их косинусное сходство — это косинус угла между ними:

∥x∥∥y∥x⊤y​∈[−1,1].

Поскольку косинусное сходство между one-hot-векторами любых двух разных слов равно 0, one-hot-векторы не могут кодировать сходство между словами.

14.1.2 Самоконтролируемый word2vec

Инструмент word2vec предложен именно для решения этой проблемы. Он отображает каждое слово в вектор фиксированной длины, и эти векторы лучше выражают сходство и аналогии между разными словами. Инструмент word2vec включает две модели: модель skip-gram («пропуск-грамма») (Mikolov et al., 2013b) и непрерывный мешок слов (continuous bag of words, CBOW) (Mikolov et al., 2013a). Чтобы получить семантически осмысленные представления, их обучение опирается на условные вероятности, которые можно рассматривать как предсказание одних слов корпуса по другим. Поскольку размеченных данных нет, и skip-gram, и CBOW — самоконтролируемые модели.

Ниже мы опишем эти две модели и методы их обучения.

14.1.3 Модель skip-gram

Модель skip-gram предполагает, что слово можно использовать для порождения окружающих его слов в текстовой последовательности. Возьмём в качестве примера последовательность «the», «man», «loves», «his», «son». Пусть центральным словом выбрано «loves», а размер контекстного окна равен 2. Как показано на рис. 14.1.1, при заданном центральном слове «loves» модель skip-gram рассматривает условную вероятность порождения контекстных слов «the», «man», «his», «son»:

P("the","man","his","son"∣"loves").

Предположим, что контекстные слова порождаются независимо при заданном центральном слове (условная независимость). Тогда указанную условную вероятность можно переписать так:

P("the"∣"loves")⋅P("man"∣"loves")⋅P("his"∣"loves")⋅P("son"∣"loves").

Рис. 14.1.1. Модель skip-gram рассматривает условную вероятность порождения окружающих контекстных слов при заданном центральном слове

В модели skip-gram у каждого слова есть два d-мерных вектора, которые используются для вычисления условных вероятностей. Точнее, для слова с индексом i в словаре обозначим через vi​∈Rd и ui​∈Rd два его вектора, когда оно выступает центральным словом и контекстным словом соответственно. Условную вероятность порождения любого контекстного слова wo​ (с индексом o в словаре) при заданном центральном слове wc​ (с индексом c в словаре) можно смоделировать операцией softmax над скалярными произведениями векторов:

P(wo​∣wc​)=∑i∈V​exp(ui⊤​vc​)exp(uo⊤​vc​)​,(14.1.1)

где множество индексов словаря V={0,1,…,∣V∣−1}. Пусть дана текстовая последовательность длины T, где слово на временном шаге t обозначено w(t). Предположим, что контекстные слова порождаются независимо при любом центральном слове. Для контекстного окна размера m функция правдоподобия модели skip-gram — это вероятность порождения всех контекстных слов при любом заданном центральном слове:

t=1∏T​−m≤j≤m, j=0∏​P(w(t+j)∣w(t)),

где можно опустить любые временные шаги, меньшие 1 или большие T.

14.1.3.1 Обучение

Параметры модели skip-gram — это вектор центрального слова и вектор контекстного слова для каждого слова словаря. При обучении мы находим параметры модели, максимизируя функцию правдоподобия (то есть методом максимального правдоподобия). Это равносильно минимизации следующей функции потерь:

−t=1∑T​−m≤j≤m, j=0∑​logP(w(t+j)∣w(t)).

Если для минимизации потерь используется стохастический градиентный спуск, то на каждой итерации можно случайно выбирать более короткую подпоследовательность, вычислять по ней (стохастический) градиент и обновлять параметры модели. Для вычисления этого (стохастического) градиента нужно получить градиенты логарифма условной вероятности по вектору центрального слова и по векторам контекстных слов. В общем случае, согласно (14.1.1), логарифм условной вероятности для центрального слова wc​ и контекстного слова wo​ равен

logP(wo​∣wc​)=uo⊤​vc​−log(i∈V∑​exp(ui⊤​vc​)).(14.1.2)

Дифференцируя, получаем градиент по вектору центрального слова vc​:

∂vc​∂logP(wo​∣wc​)​​=uo​−∑i∈V​exp(ui⊤​vc​)∑j∈V​exp(uj⊤​vc​)uj​​=uo​−j∈V∑​(∑i∈V​exp(ui⊤​vc​)exp(uj⊤​vc​)​)uj​=uo​−j∈V∑​P(wj​∣wc​)uj​.​(14.1.3)

Обратите внимание: для вычисления в (14.1.3) нужны условные вероятности всех слов словаря при центральном слове wc​. Градиенты для остальных векторов слов получаются аналогично.

После обучения для слова с индексом i словаря мы получаем два вектора: vi​ (как для центрального слова) и ui​ (как для контекстного слова). В приложениях обработки естественного языка в качестве представления слова обычно используют вектор центрального слова модели skip-gram.

14.1.4 Модель непрерывного мешка слов (CBOW)

Модель непрерывного мешка слов (CBOW) похожа на модель skip-gram. Главное отличие в том, что CBOW предполагает: центральное слово порождается по окружающим его контекстным словам в текстовой последовательности. Например, в последовательности «the», «man», «loves», «his», «son» при центральном слове «loves» и контекстном окне размера 2 модель CBOW рассматривает условную вероятность порождения центрального слова «loves» по контекстным словам «the», «man», «his», «son» (как показано на рис. 14.1.2), то есть

P("loves"∣"the","man","his","son").

Рис. 14.1.2. Модель непрерывного мешка слов рассматривает условную вероятность порождения центрального слова по окружающим контекстным словам

Поскольку в модели CBOW несколько контекстных слов, при вычислении условной вероятности векторы этих слов усредняются. Точнее, для слова с индексом i в словаре обозначим через vi​∈Rd и ui​∈Rd два вектора, используемых для контекстного и центрального слова соответственно (обозначения противоположны модели skip-gram). Условную вероятность порождения любого центрального слова wc​ (с индексом c в словаре) при заданных контекстных словах wo1​​,…,wo2m​​ (с индексами o1​,…,o2m​ в словаре) можно смоделировать формулой

P(wc​∣wo1​​,…,wo2m​​)=∑i∈V​exp(2m1​ui⊤​(vo1​​+…,+vo2m​​))exp(2m1​uc⊤​(vo1​​+…,+vo2m​​))​.(14.1.4)

Для краткости положим Wo​={wo1​​,…,wo2m​​} и vˉo​=(vo1​​+…+vo2m​​)/(2m). Тогда (14.1.4) упрощается до

P(wc​∣Wo​)=∑i∈V​exp(ui⊤​vˉo​)exp(uc⊤​vˉo​)​.

Пусть дана текстовая последовательность длины T, где слово на временном шаге t обозначено w(t). Для контекстного окна размера m функция правдоподобия модели CBOW — это вероятность порождения всех центральных слов при заданных их контекстных словах:

t=1∏T​P(w(t)∣w(t−m),…,w(t−1),w(t+1),…,w(t+m)).

14.1.4.1 Обучение

Обучение модели CBOW почти не отличается от обучения модели skip-gram. Оценка максимального правдоподобия для CBOW равносильна минимизации следующей функции потерь:

−t=1∑T​logP(w(t)∣w(t−m),…,w(t−1),w(t+1),…,w(t+m)).

Заметим, что

logP(wc​∣Wo​)=uc⊤​vˉo​−log(i∈V∑​exp(ui⊤​vˉo​)).

Дифференцируя, получаем градиент по любому вектору контекстного слова voi​​ (i=1,…,2m):

∂voi​​∂logP(wc​∣Wo​)​=2m1​​uc​−j∈V∑​∑i∈V​exp(ui⊤​vˉo​)exp(uj⊤​vˉo​)uj​​​=2m1​​uc​−j∈V∑​P(wj​∣Wo​)uj​​.(14.1.5)

Градиенты для остальных векторов слов получаются аналогично. В отличие от модели skip-gram, в CBOW в качестве представления слова обычно используют векторы контекстных слов.

Резюме

  • Векторы слов — это векторы, представляющие значение слов; их можно также считать векторами признаков слов. Технику отображения слов в вещественные векторы называют вложением слов.
  • Инструмент word2vec включает модель skip-gram и модель непрерывного мешка слов.
  • Модель skip-gram предполагает, что слово можно использовать для порождения окружающих его слов в текстовой последовательности, а модель непрерывного мешка слов — что центральное слово порождается по контекстным словам.

Упражнения

  1. Какова вычислительная сложность каждого градиента? Какие проблемы возникают, если словарь велик?
  2. Некоторые устойчивые словосочетания английского языка состоят из нескольких слов, например «new york». Как обучить для них векторы слов? Подсказка: см. раздел 4 статьи о word2vec (Mikolov et al., 2013b).
  3. Рассмотрим устройство word2vec на примере модели skip-gram. Как связаны скалярное произведение двух векторов слов в модели skip-gram и косинусное сходство? Почему косинусное сходство векторов (обученных skip-gram) для пары семантически близких слов может быть высоким?
