13.7 Одноступенчатое обнаружение с несколькими окнами (SSD)

В разделах 13.3–13.6 мы рассмотрели ограничивающие рамки, якорные рамки, обнаружение в нескольких масштабах и набор данных для обнаружения. Теперь мы готовы использовать эти знания, чтобы спроектировать модель обнаружения объектов: одноступенчатое обнаружение с несколькими окнами (single shot multibox detection, SSD) (Liu et al., 2016). Эта модель простая, быстрая и широко используется. Хотя это лишь один из многих методов обнаружения объектов, некоторые проектные решения и детали реализации из этого раздела применимы и к другим моделям.

13.7.1 Модель

На рис. 13.7.1 показана архитектура модели SSD. Модель в основном состоит из базовой сети, за которой следуют несколько блоков многомасштабных признаков. Базовая сеть извлекает признаки из входного изображения, поэтому в ней можно использовать глубокую свёрточную сеть. В оригинальной статье SSD базовой сетью была VGG, обрезанная перед слоем классификации (Liu et al., 2016); сейчас её также часто заменяют на ResNet. Базовую сеть можно спроектировать так, чтобы её выход имел большие высоту и ширину. Тогда на основе этой карты признаков будет создано больше якорных рамок, которые помогут обнаруживать мелкие объекты. Каждый следующий блок многомасштабных признаков уменьшает высоту и ширину карты признаков, полученной от предыдущего слоя (например, вдвое), и расширяет рецептивное поле каждого элемента карты признаков на входном изображении.

Напомним из раздела 13.5 идею обнаружения в нескольких масштабах: глубокая нейронная сеть строит иерархическое представление изображения. Карты признаков, расположенные ближе к верху рис. 13.7.1, малы, но имеют большое рецептивное поле, поэтому они подходят для обнаружения меньшего количества, но более крупных объектов. Итак, с помощью блоков многомасштабных признаков SSD создаёт якорные рамки разных размеров и обнаруживает объекты разных размеров, предсказывая классы и смещения ограничивающих рамок. Поэтому это модель обнаружения в нескольких масштабах.

Рис. 13.7.1. Модель одноступенчатого обнаружения с несколькими окнами состоит из базового блока и нескольких блоков многомасштабных признаков, соединённых последовательно

Далее мы рассмотрим детали реализации отдельных блоков на рис. 13.7.1. Сначала обсудим, как реализовать предсказание классов и ограничивающих рамок.

13.7.1.1 Слой предсказания классов

Пусть количество классов объектов равно q. Тогда у якорных рамок q+1 класс, где класс 0 — фон. Пусть на некотором масштабе высота и ширина карты признаков равны h и w. Если с центром в каждом её элементе создать a якорных рамок, то нужно классифицировать hwa якорных рамок. Если использовать полносвязный слой для выхода, легко получить слишком много параметров модели. Вспомним метод из раздела 7.3, в котором каналы свёрточного слоя используются для вывода предсказаний классов: одноступенчатое обнаружение с несколькими окнами применяет тот же подход, чтобы снизить сложность модели.

Конкретно, слой предсказания классов использует свёрточный слой, который сохраняет высоту и ширину входа. Тогда выход и вход соответствуют друг другу по пространственным координатам карты признаков. Рассмотрим одну и ту же пространственную позицию (x, y) на выходе и на входе: каналы выходной карты признаков в этой позиции содержат предсказания классов для всех якорных рамок, созданных с центром в позиции (x, y) входной карты признаков. Поэтому число выходных каналов равно a(q+1), и канал с индексом i(q+1)+j (0≤j≤q) соответствует предсказанию для якорной рамки с индексом i и класса с индексом j.

Ниже мы определяем такой слой предсказания классов; параметры num_anchors и num_classes задают a и q соответственно. Слой использует свёртку 3×3 с заполнением 1. Высота и ширина входа и выхода этого свёрточного слоя не меняются.

MXNet:

%matplotlib inline

from mxnet.gluon import nn

npx.set_np()

def cls_predictor(num_anchors, num_classes):
    return nn.Conv2D(num_anchors * (num_classes + 1), kernel_size=3,
                     padding=1)

13.7.1.2 Слой предсказания ограничивающих рамок

Слой предсказания ограничивающих рамок устроен так же, как слой предсказания классов. Единственное отличие в том, что для каждой якорной рамки здесь нужно предсказать 4 смещения, а не q+1 значений классов.

MXNet:

def bbox_predictor(num_anchors):
    return nn.Conv2D(num_anchors * 4, kernel_size=3, padding=1)

PyTorch:

def bbox_predictor(num_inputs, num_anchors):
    return nn.Conv2d(num_inputs, num_anchors * 4, kernel_size=3, padding=1)

PaddlePaddle:

def bbox_predictor(num_inputs, num_anchors):
    return nn.Conv2D(num_inputs, num_anchors * 4, kernel_size=3, padding=1)

13.7.1.3 Объединение предсказаний разных масштабов

Как мы уже говорили, SSD использует карты признаков разных масштабов, чтобы создавать якорные рамки и предсказывать их классы и смещения. На разных масштабах форма карт признаков или число якорных рамок с центром в одном элементе могут различаться. Поэтому формы предсказаний на разных масштабах могут отличаться.

В следующем примере мы строим для одного минибатча две карты признаков разных масштабов (Y1 и Y2), где высота и ширина Y2 вдвое меньше, чем у Y1. В качестве примера возьмём предсказание классов: допустим, каждый элемент Y1 и Y2 создаёт соответственно 5 и 3 якорные рамки. Допустим также, что число классов объектов равно 10. Тогда число каналов в выходе предсказания классов для карт признаков Y1 и Y2 равно 5×(10+1)=55 и 3×(10+1)=33 соответственно. Форма любого выхода — (размер батча, число каналов, высота, ширина).

MXNet:

def forward(x, block):
    block.initialize()
    return block(x)

Y1 = forward(np.zeros((2, 8, 20, 20)), cls_predictor(5, 10))
Y2 = forward(np.zeros((2, 16, 10, 10)), cls_predictor(3, 10))
Y1.shape, Y2.shape

PyTorch:

def forward(x, block):
    return block(x)

Y1 = forward(torch.zeros((2, 8, 20, 20)), cls_predictor(8, 5, 10))
Y2 = forward(torch.zeros((2, 16, 10, 10)), cls_predictor(16, 3, 10))
Y1.shape, Y2.shape

PaddlePaddle:

Как видно, кроме размера батча, все остальные три измерения у двух выходов разные. Чтобы объединить эти два выхода предсказаний и повысить эффективность вычислений, мы приведём тензоры к более единообразному формату.

Измерение каналов содержит предсказания для якорных рамок с одним и тем же центром. Сначала мы переносим измерение каналов в последнее место. Поскольку размер батча на разных масштабах не меняется, мы можем привести предсказания к двумерному виду (размер батча, высота × ширина × число каналов), что удобно для последующего объединения по измерению 1.

MXNet:

def flatten_pred(pred):
    return npx.batch_flatten(pred.transpose(0, 2, 3, 1))

def concat_preds(preds):
    return np.concatenate([flatten_pred(p) for p in preds], axis=1)

PyTorch:

def flatten_pred(pred):
    return torch.flatten(pred.permute(0, 2, 3, 1), start_dim=1)

def concat_preds(preds):
    return torch.cat([flatten_pred(p) for p in preds], dim=1)

PaddlePaddle:

def flatten_pred(pred):
    return paddle.flatten(pred.transpose([0, 2, 3, 1]), start_axis=1)

def concat_preds(preds):
    return paddle.concat([flatten_pred(p) for p in preds], axis=1)

Так, хотя Y1 и Y2 различаются по числу каналов, высоте и ширине, мы всё равно можем объединить эти два выхода предсказаний для одного минибатча на двух разных масштабах.

concat_preds([Y1, Y2]).shape

13.7.1.4 Блок уменьшения высоты и ширины вдвое

Чтобы обнаруживать объекты на нескольких масштабах, мы определяем блок down_sample_blk, который уменьшает вдвое высоту и ширину входной карты признаков. По сути, этот блок устроен по образцу VGG-блока из раздела 7.2. Точнее, каждый блок уменьшения вдвое состоит из двух свёрточных слоёв 3×3 с заполнением 1 и слоя максимального пулинга 2×2 с шагом 2. Мы знаем, что свёрточный слой 3×3 с заполнением 1 не меняет форму карты признаков. Однако последующий слой максимального пулинга 2×2 уменьшает высоту и ширину входной карты признаков вдвое. Для входа и выхода этого блока, поскольку 1×2+(3−1)+(3−1)=6, каждый элемент выхода имеет рецептивное поле 6×6 на входе. Поэтому блок уменьшения вдвое расширяет рецептивное поле каждого элемента в выходной карте признаков.

MXNet:

def down_sample_blk(num_channels):
    blk = nn.Sequential()
    for _ in range(2):
        blk.add(nn.Conv2D(num_channels, kernel_size=3, padding=1),
                nn.BatchNorm(in_channels=num_channels),
                nn.Activation('relu'))
    blk.add(nn.MaxPool2D(2))
    return blk

PyTorch:

def down_sample_blk(in_channels, out_channels):
    blk = []
    for _ in range(2):
        blk.append(nn.Conv2d(in_channels, out_channels,
                             kernel_size=3, padding=1))
        blk.append(nn.BatchNorm2d(out_channels))
        blk.append(nn.ReLU())
        in_channels = out_channels
    blk.append(nn.MaxPool2d(2))
    return nn.Sequential(*blk)

PaddlePaddle:

def down_sample_blk(in_channels, out_channels):
    blk = []
    for _ in range(2):
        blk.append(nn.Conv2D(in_channels, out_channels,
                             kernel_size=3, padding=1))
        blk.append(nn.BatchNorm2D(out_channels))
        blk.append(nn.ReLU())
        in_channels = out_channels
    blk.append(nn.MaxPool2D(2))
    return nn.Sequential(*blk)

В следующем примере блок уменьшения вдвое меняет число входных каналов и вдвое уменьшает высоту и ширину входной карты признаков.

13.7.1.5 Базовый блок сети

Базовый блок сети извлекает признаки из входного изображения. Для простоты вычислений мы строим небольшую базовую сеть, которая последовательно соединяет 3 блока уменьшения вдвое и постепенно удваивает число каналов. При входном изображении размером 256×256 этот базовый блок выдаёт карту признаков размером 32×32 (256/23=32).

MXNet:

def base_net():
    blk = nn.Sequential()
    for num_filters in [16, 32, 64]:
        blk.add(down_sample_blk(num_filters))
    return blk

forward(np.zeros((2, 3, 256, 256)), base_net()).shape

PyTorch:

def base_net():
    blk = []
    num_filters = [3, 16, 32, 64]
    for i in range(len(num_filters) - 1):
        blk.append(down_sample_blk(num_filters[i], num_filters[i+1]))
    return nn.Sequential(*blk)

forward(torch.zeros((2, 3, 256, 256)), base_net()).shape

PaddlePaddle:

13.7.1.6 Полная модель

Полная модель одноступенчатого обнаружения с несколькими окнами состоит из пяти блоков. Карта признаков, которую выдаёт каждый блок, используется и для создания якорных рамок, и для предсказания их классов и смещений. Из этих пяти блоков первый — базовый блок сети, со второго по четвёртый — блоки уменьшения вдвое, а последний блок использует глобальный максимальный пулинг, чтобы уменьшить высоту и ширину до 1. Технически блоки со второго по пятый — это блоки многомасштабных признаков с рис. 13.7.1.

MXNet:

def get_blk(i):
    if i == 0:
        blk = base_net()
    elif i == 4:
        blk = nn.GlobalMaxPool2D()
    else:
        blk = down_sample_blk(128)
    return blk

PyTorch:

def get_blk(i):
    if i == 0:
        blk = base_net()
    elif i == 1:
        blk = down_sample_blk(64, 128)
    elif i == 4:
        blk = nn.AdaptiveMaxPool2d((1,1))
    else:
        blk = down_sample_blk(128, 128)
    return blk

PaddlePaddle:

def get_blk(i):
    if i == 0:
        blk = base_net()
    elif i == 1:
        blk = down_sample_blk(64, 128)
    elif i == 4:
        blk = nn.AdaptiveMaxPool2D((1,1))
    else:
        blk = down_sample_blk(128, 128)
    return blk

Теперь определим прямое распространение для каждого блока. В отличие от задачи классификации изображений, выход здесь включает: карту признаков Y свёрточной сети; якорные рамки, созданные по Y на текущем масштабе; предсказанные по Y классы и смещения этих якорных рамок.

MXNet:

def blk_forward(X, blk, size, ratio, cls_predictor, bbox_predictor):
    Y = blk(X)
    anchors = d2l.multibox_prior(Y, sizes=size, ratios=ratio)
    cls_preds = cls_predictor(Y)
    bbox_preds = bbox_predictor(Y)
    return (Y, anchors, cls_preds, bbox_preds)

PyTorch:

PaddlePaddle:

def blk_forward(X, blk, size, ratio, cls_predictor, bbox_predictor):

Напомним, что на рис. 13.7.1 блок многомасштабных признаков ближе к верху предназначен для обнаружения крупных объектов, поэтому ему нужны якорные рамки большего размера. В приведённом выше прямом распространении для каждого блока многомасштабных признаков мы передаём в функцию multibox_prior через параметр sizes список из двух значений масштаба. Ниже интервал от 0.2 до 1.05 равномерно делится на пять частей, чтобы задать меньшие значения масштаба для пяти блоков: 0.2, 0.37, 0.54, 0.71 и 0.88. Большие значения масштаба для каждого блока вычисляются как 0.2×0.37​=0.272, 0.37×0.54​=0.447 и так далее.

sizes = [[0.2, 0.272], [0.37, 0.447], [0.54, 0.619], [0.71, 0.79],
         [0.88, 0.961]]
ratios = [[1, 2, 0.5]] * 5
num_anchors = len(sizes[0]) + len(ratios[0]) - 1

Теперь мы можем определить полную модель TinySSD следующим образом.

MXNet:

class TinySSD(nn.Block):
    def __init__(self, num_classes, **kwargs):
        super(TinySSD, self).__init__(**kwargs)
        self.num_classes = num_classes
        for i in range(5):
            # Эквивалентно присваиванию self.blk_i = get_blk(i)
            setattr(self, f'blk_{i}', get_blk(i))
            setattr(self, f'cls_{i}', cls_predictor(num_anchors, num_classes))
            setattr(self, f'bbox_{i}', bbox_predictor(num_anchors))

    def forward(self, X):
        anchors, cls_preds, bbox_preds = [None] * 5, [None] * 5, [None] * 5
        for i in range(5):
            # getattr(self, 'blk_%d' % i) — это обращение к self.blk_i
            X, anchors[i], cls_preds[i], bbox_preds[i] = blk_forward(
                X, getattr(self, f'blk_{i}'), sizes[i], ratios[i],
                getattr(self, f'cls_{i}'), getattr(self, f'bbox_{i}'))
        anchors = np.concatenate(anchors, axis=1)
        cls_preds = concat_preds(cls_preds)
        cls_preds = cls_preds.reshape(
            cls_preds.shape[0], -1, self.num_classes + 1)
        bbox_preds = concat_preds(bbox_preds)
        return anchors, cls_preds, bbox_preds

            # Эквивалентно присваиванию self.blk_i = get_blk(i)
            setattr(self, f'blk_{i}', get_blk(i))
            setattr(self, f'cls_{i}', cls_predictor(idx_to_in_channels[i],
                                                    num_anchors, num_classes))
            setattr(self, f'bbox_{i}', bbox_predictor(idx_to_in_channels[i],
                                                      num_anchors))

    def forward(self, X):
        anchors, cls_preds, bbox_preds = [None] * 5, [None] * 5, [None] * 5
        for i in range(5):
            # getattr(self, 'blk_%d' % i) — это обращение к self.blk_i
            X, anchors[i], cls_preds[i], bbox_preds[i] = blk_forward(
                X, getattr(self, f'blk_{i}'), sizes[i], ratios[i],
                getattr(self, f'cls_{i}'), getattr(self, f'bbox_{i}'))
        anchors = paddle.concat(anchors, axis=1)
        cls_preds = concat_preds(cls_preds)
        cls_preds = cls_preds.reshape(
            (cls_preds.shape[0], -1, self.num_classes + 1))
        bbox_preds = concat_preds(bbox_preds)
        return anchors, cls_preds, bbox_preds

Создадим экземпляр модели и выполним прямое распространение для минибатча изображений X размером 256×256 пикселей.

Как показано выше, первый блок выдаёт карту признаков размером 32×32. Напомним, что со второго по четвёртый блоки — это блоки уменьшения вдвое, а пятый блок — глобальный слой пулинга. Поскольку с центром в каждом элементе карты признаков создаются 4 якорные рамки, на всех пяти масштабах для одного изображения получается (322+162+82+42+1)×4=5444 якорных рамок.

13.7.2.2 Определение функций потерь и оценки

Для обнаружения объектов есть два типа потерь. Первый — потеря, связанная с классами якорных рамок: её можно вычислить с помощью функции кросс-энтропии, которую мы использовали в задачах классификации. Второй — потеря, связанная со смещениями положительных якорных рамок: предсказание смещений — это задача регрессии. Однако здесь для этой задачи мы не используем квадратичную потерю из раздела 3.1, а берём потерю в норме L1​, то есть модуль разности предсказанного и истинного значений. Маска bbox_masks исключает из вычисления потерь отрицательные и фиктивные (дополняющие) якорные рамки. Наконец, мы складываем потери классов и смещений якорных рамок и получаем итоговую функцию потерь модели.

MXNet:

cls_loss = gluon.loss.SoftmaxCrossEntropyLoss()
bbox_loss = gluon.loss.L1Loss()

def calc_loss(cls_preds, cls_labels, bbox_preds, bbox_labels, bbox_masks):
    cls = cls_loss(cls_preds, cls_labels)
    bbox = bbox_loss(bbox_preds * bbox_masks, bbox_labels * bbox_masks)
    return cls + bbox

PyTorch:

bbox_loss = nn.L1Loss(reduction='none')

    cls = cls_loss(cls_preds.reshape(-1, num_classes),
                   cls_labels.reshape(-1)).reshape(batch_size, -1).mean(dim=1)
    bbox = bbox_loss(bbox_preds * bbox_masks,
                     bbox_labels * bbox_masks).mean(dim=1)
    return cls + bbox

Для оценки результатов классификации можно использовать точность. Поскольку для смещений применяется потеря в норме L1​, для оценки предсказаний ограничивающих рамок мы используем среднюю абсолютную ошибку (mean absolute error). Эти предсказания получаются из созданных якорных рамок и их предсказанных смещений.

MXNet:

def cls_eval(cls_preds, cls_labels):
    # Поскольку предсказания классов находятся в последнем измерении, в argmax нужно указать последнее измерение.
    return float((cls_preds.argmax(axis=-1).astype(
        cls_labels.dtype) == cls_labels).sum())

def bbox_eval(bbox_preds, bbox_labels, bbox_masks):
    return float((np.abs((bbox_labels - bbox_preds) * bbox_masks)).sum())

PyTorch:

13.7.2.3 Обучение модели

При обучении модели в прямом распространении мы генерируем многомасштабные якорные рамки (anchors) и предсказываем их классы (cls_preds) и смещения (bbox_preds). Затем по разметке Y мы размечаем классы (cls_labels) и смещения (bbox_labels) якорных рамок. В конце мы вычисляем функцию потерь по предсказанным и размеченным классам и смещениям. Для краткости тестовый набор данных здесь не оценивается.

MXNet:

num_epochs, timer = 20, d2l.Timer()
animator = d2l.Animator(xlabel='эпоха', xlim=[1, num_epochs],
                        legend=['ошибка классов', 'MAE рамок'])
for epoch in range(num_epochs):
    # Метрики: сумма верных предсказаний классов, число предсказаний классов,
    # сумма абсолютных ошибок рамок, число значений в этой сумме
    metric = d2l.Accumulator(4)
    for features, target in train_iter:
        timer.start()
        X = features.as_in_ctx(device)
        Y = target.as_in_ctx(device)
        with autograd.record():
            # Генерируем многомасштабные якорные рамки и предсказываем для каждой из них класс и смещение
            anchors, cls_preds, bbox_preds = net(X)
            # Размечаем классы и смещения для каждой якорной рамки
            bbox_labels, bbox_masks, cls_labels = d2l.multibox_target(anchors,
                                                                      Y)
            # По предсказанным и размеченным классам и смещениям вычисляем функцию потерь
            l = calc_loss(cls_preds, cls_labels, bbox_preds, bbox_labels,
                          bbox_masks)
        l.backward()
        trainer.step(batch_size)
        metric.add(cls_eval(cls_preds, cls_labels), cls_labels.size,
                   bbox_eval(bbox_preds, bbox_labels, bbox_masks),
                   bbox_labels.size)
    cls_err, bbox_mae = 1 - metric[0] / metric[1], metric[2] / metric[3]
    animator.add(epoch + 1, (cls_err, bbox_mae))
print(f'ошибка классов {cls_err:.2e}, MAE рамок {bbox_mae:.2e}')
print(f'{len(train_iter._dataset) / timer.stop():.1f} примеров/с на '
      f'{str(device)}')

Резюме

  • Одноступенчатое обнаружение с несколькими окнами — это модель обнаружения в нескольких масштабах. На основе базового блока сети и нескольких блоков многомасштабных признаков SSD создаёт якорные рамки разного числа и размера и обнаруживает объекты разного размера, предсказывая классы и смещения этих якорных рамок.
  • При обучении модели одноступенчатого обнаружения с несколькими окнами функция потерь вычисляется по предсказанным и размеченным классам и смещениям якорных рамок.

Упражнения

  1. Можно ли улучшить одноступенчатое обнаружение с несколькими окнами, изменив функцию потерь? Например, заменить потерю в норме L1​, которую мы используем для предсказания смещений, на сглаженную потерю в норме L1​. Вблизи нуля она использует квадратичную функцию и поэтому становится более гладкой. Эта гладкость задаётся гиперпараметром σ:

f(x)={(σx)2/2,∣x∣−0.5/σ2,​если ∣x∣<1/σ2в остальных случаях​

При очень большом σ эта потеря похожа на потерю в норме L1​. Когда значение σ мало, функция потерь становится более гладкой.

MXNet:

sigmas = [10, 1, 0.5]

d2l.set_figsize()

for l, s in zip(lines, sigmas):
    y = npx.smooth_l1(x, scalar=s)
    d2l.plt.plot(x.asnumpy(), y.asnumpy(), l, label='sigma=%.1f' % s)
d2l.plt.legend();

PyTorch:

def smooth_l1(data, scalar):
    out = []
    for i in data:
        if abs(i) < 1 / (scalar ** 2):
            out.append(((scalar * i) ** 2) / 2)
        else:
            out.append(abs(i) - 0.5 / (scalar ** 2))
    return torch.tensor(out)

Кроме того, для предсказания классов в эксперименте использовалась кросс-энтропия: если предсказанная вероятность истинного класса j равна pj​, то потеря равна −logpj​. Также можно использовать фокальную потерю (Lin et al., 2017). При заданных гиперпараметрах γ>0 и α>0 эта потеря определяется так:

−α(1−pj​)γlogpj​.

Видно, что увеличение γ эффективно уменьшает относительную потерю для примеров с большой предсказанной вероятностью правильного класса (например, pj​>0.5), поэтому обучение может сосредоточиться на трудных примерах, которые классифицируются неверно.

  1. Из-за ограничений объёма в этом разделе мы опустили некоторые детали реализации модели одноступенчатого обнаружения с несколькими окнами. Можно ли улучшить модель в следующих направлениях:
    1. когда объекты намного меньше изображения, модель может увеличить входное изображение;
    2. обычно есть много отрицательных якорных рамок. Чтобы распределение классов было более сбалансированным, можно уменьшить вдвое высоту и ширину отрицательных якорных рамок;
    3. в функции потерь задать гиперпараметры, которые по-разному взвешивают потерю классов и потерю смещений;
    4. оценивать модель обнаружения объектов другими методами, например теми, что описаны в статье об одноступенчатом обнаружении с несколькими окнами (Liu et al., 2016).
