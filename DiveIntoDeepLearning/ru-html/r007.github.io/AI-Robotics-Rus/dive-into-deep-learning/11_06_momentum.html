Погружение в глубокое обучение

11.6 Метод импульса

В разделе 11.4 мы подробно разобрали стохастический градиентный спуск, то есть что происходит при оптимизации, когда доступны только зашумлённые градиенты. Для зашумлённых градиентов мы должны особенно внимательно выбирать скорость обучения. Если она уменьшается слишком быстро, сходимость останавливается. Если же уменьшение слишком медленное, мы можем не сойтись к оптимальному решению.

11.6.1 Основы

В этом разделе рассматриваются более эффективные алгоритмы оптимизации, в первую очередь для некоторых типов задач, которые часто встречаются на практике.

11.6.1.1 Экспоненциально затухающее среднее

В предыдущем разделе мы рассматривали минибатчевый стохастический градиентный спуск как способ ускорить вычисления. У него есть и приятный побочный эффект: усреднение градиентов уменьшает дисперсию. Минибатчевый стохастический градиентный спуск можно вычислить так:

gt,t−1​=∂w​∣Bt​∣1​i∈Bt​∑​f(xi​,wt−1​)=∣Bt​∣1​i∈Bt​∑​hi,t−1​.

Чтобы сохранить обозначения простыми, здесь мы используем hi,t−1​=∂w​f(xi​,wt−1​) как стохастический градиент для примера i при весах wt−1​, обновлённых на шаге t−1. Было бы хорошо, если бы мы могли воспользоваться эффектом снижения дисперсии даже сверх усреднения градиентов по минибатчу. Один из вариантов решения этой задачи — заменить вычисление градиента экспоненциально затухающим средним (leaky average):

vt​=βvt−1​+gt,t−1​,

где β∈(0,1). Это эффективно заменяет мгновенный градиент усреднённым значением нескольких «прошлых» градиентов. v называют импульсом (momentum), он накапливает прошлые градиенты. Чтобы объяснить это подробнее, рекурсивно раскроем vt​:

vt​=β2vt−2​+βgt−1,t−2​+gt,t−1​=…,=τ=0∑t−1​βτgt−τ,t−τ−1​.​

Большое β соответствует длинному среднему, тогда как малое β лишь немного корректирует обычный градиентный спуск. Новый градиент больше не указывает направление наибольшего спуска для конкретного примера, а указывает направление взвешенного среднего прошлых градиентов. Это позволяет получить большую часть выгоды от усреднения по батчу, не платя за фактическое вычисление градиента для каждого из них.

Описанные рассуждения лежат в основе «ускоренных» методов градиента, например, градиентного спуска с импульсом. Для задач оптимизации с плохой обусловленностью (например, когда одни направления продвигаются гораздо медленнее других, как в узкой долине) ускоренные методы дают дополнительный выигрыш в эффективности. Кроме того, они позволяют усреднять последующие градиенты, чтобы получить более устойчивое направление спуска. Надо признать, что даже для задач выпуклой оптимизации без шума ускорение — одна из ключевых причин, по которым импульс так хорошо работает.

Как и следовало ожидать, благодаря своей эффективности импульс стал предметом активных исследований в глубоком обучении и последующей оптимизации. Например, см. статью (автор — Goh, 2017), в которой приведён подробный анализ и интерактивные анимации. Импульс был предложен в работе (Polyak, 1964). Nesterov (2018) подробно рассматривает его теорию в контексте выпуклой оптимизации. Давно известно, что импульс полезен и в глубоком обучении. Подробности с примерами см. в обсуждении у (Sutskever et al., 2013).

11.6.1.2 Плохо обусловленные задачи

Чтобы лучше понять геометрию метода импульса, вспомним градиентный спуск, хотя его целевая функция явно менее приятна. Напомним, что в разделе 11.3 мы использовали f(x)=x12​+2x22​ — умеренно вытянутый эллипсоид. Мы сделаем эту функцию ещё более вытянутой, растянув её вдоль направления x1​:

f(x)=0.1x12​+2x22​.

Как и прежде, f имеет минимум в точке (0,0). Эта функция очень плоская в направлении x1​. Посмотрим, что происходит при градиентном спуске для этой новой функции.

MXNet:

%matplotlib inline
from d2l import mxnet as d2l
from mxnet import np, npx
npx.set_np()

eta = 0.4
def f_2d(x1, x2):
    return 0.1 * x1 ** 2 + 2 * x2 ** 2
def gd_2d(x1, x2, s1, s2):
    return (x1 - eta * 0.2 * x1, x2 - eta * 4 * x2, 0, 0)

d2l.show_trace_2d(f_2d, d2l.train_2d(gd_2d))

PyTorch:

По построению градиент в направлении x2​ гораздо больше и меняется гораздо быстрее, чем горизонтальный градиент по x1​. Поэтому мы оказываемся в затруднительном положении: если выбрать малую скорость обучения, мы гарантируем, что решение не будет расходиться в направлении x2​, но миримся с медленной сходимостью по x1​. Наоборот, при большой скорости обучения мы быстро продвигаемся по x1​, но расходимся по x2​. Следующий пример показывает, что даже при небольшом увеличении скорости обучения с 0.4 до 0.6 поведение меняется. Сходимость по x1​ улучшается, но в целом качество решения становится хуже.

eta = 0.6
d2l.show_trace_2d(f_2d, d2l.train_2d(gd_2d))

11.6.1.3 Метод импульса

Метод импульса (momentum) позволяет решить описанную выше проблему градиентного спуска. Глядя на траекторию оптимизации выше, можно предположить, что вычисление усреднённого прошлого градиента должно хорошо работать. В самом деле, в направлении x1​ это позволит суммировать хорошо согласованные градиенты и тем самым увеличит расстояние, которое мы проходим на каждом шаге. Напротив, в направлении x2​, где градиент колеблется, усреднённый градиент уменьшит размер шага, поскольку колебания взаимно гасятся. Использование vt​ вместо градиента gt​ даёт следующие уравнения обновления:

vt​xt​​←βvt−1​+gt,t−1​,←xt−1​−ηt​vt​.​

Заметим, что при β=0 мы получаем обычный градиентный спуск. Прежде чем углубляться в математические свойства метода, быстро посмотрим, как он работает на практике.

def momentum_2d(x1, x2, v1, v2):
    v1 = beta * v1 + 0.2 * x1
    v2 = beta * v2 + 4 * x2
    return x1 - eta * v1, x2 - eta * v2, v1, v2

eta, beta = 0.6, 0.5
d2l.show_trace_2d(f_2d, d2l.train_2d(momentum_2d))

Как видно, несмотря на ту же скорость обучения, что и раньше, метод импульса хорошо сходится. Посмотрим, что будет, если уменьшить параметр импульса. Если уменьшить его вдвое, до β=0.25, траектория почти не сходится. Тем не менее это намного лучше, чем расходимость без импульса.

eta, beta = 0.6, 0.25
d2l.show_trace_2d(f_2d, d2l.train_2d(momentum_2d))

Заметим, что метод импульса можно комбинировать со стохастическим градиентным спуском, в частности с минибатчевым стохастическим градиентным спуском. Единственное отличие в том, что в этом случае мы заменяем градиент gt,t−1​ на gt​. Для удобства инициализируем v0​=0 в момент времени t=0.

11.6.1.4 Эффективные веса выборок

Напомним, что vt​=∑τ=0t−1​βτgt−τ,t−τ−1​. В предельном случае ∑τ=0∞​βτ=1−β1​. Иначе говоря, вместо шага η в градиентном спуске или стохастическом градиентном спуске мы используем шаг 1−βη​ и одновременно учитываем потенциально лучшее направление спуска. Это сочетает в себе два преимущества. Чтобы показать, как влияют разные значения β на веса, посмотрите на график ниже.

d2l.set_figsize()
betas = [0.95, 0.9, 0.6, 0]
for beta in betas:
    x = d2l.numpy(d2l.arange(40))
    d2l.plt.plot(x, beta ** x, label=f'β = {beta:.2f}')
d2l.plt.xlabel('время')
d2l.plt.legend();

11.6.2 Практические эксперименты

Посмотрим, как метод импульса работает на практике. Для этого нам нужна более масштабируемая реализация.

11.6.2.1 Реализация с нуля

По сравнению с минибатчевым стохастическим градиентным спуском метод импульса требует хранения дополнительного набора вспомогательных переменных — скоростей. Они имеют ту же форму, что и градиенты и переменные задачи оптимизации. В приведённой ниже реализации мы называем эти переменные states.

MXNet, PyTorch:

def init_momentum_states(feature_dim):
    v_w = d2l.zeros((feature_dim, 1))
    v_b = d2l.zeros(1)
    return (v_w, v_b)

TensorFlow:

def init_momentum_states(features_dim):
    v_w = tf.Variable(d2l.zeros((features_dim, 1)))
    v_b = tf.Variable(d2l.zeros(1))
    return (v_w, v_b)

PaddlePaddle:

def init_momentum_states(feature_dim):
    v_w = d2l.zeros((feature_dim, 1))
    v_b = d2l.zeros([1])
    return (v_w, v_b)

MXNet:

def sgd_momentum(params, states, hyperparams):
    for p, v in zip(params, states):
        v[:] = hyperparams['momentum'] * v + p.grad
        p[:] -= hyperparams['lr'] * v

PyTorch:

def sgd_momentum(params, states, hyperparams):
    for p, v in zip(params, states):
        with torch.no_grad():
            v[:] = hyperparams['momentum'] * v + p.grad
            p[:] -= hyperparams['lr'] * v
        p.grad.data.zero_()

TensorFlow:

def sgd_momentum(params, grads, states, hyperparams):
    for p, v, g in zip(params, states, grads):
            v[:].assign(hyperparams['momentum'] * v + g)
            p[:].assign(p - hyperparams['lr'] * v)

PaddlePaddle:

def sgd_momentum(params, states, hyperparams):
    a = []
    for p, v in zip(params, states):
        with paddle.no_grad():
            v[:] = hyperparams['momentum'] * v + p.grad
            p[:] -= hyperparams['lr'] * v
        p.grad.zero_()
        a.append(p)
    return a

Посмотрим, как это работает на практике.

def train_momentum(lr, momentum, num_epochs=2):
    d2l.train_ch11(sgd_momentum, init_momentum_states(feature_dim),
                   {'lr': lr, 'momentum': momentum}, data_iter,
                   feature_dim, num_epochs)

data_iter, feature_dim = d2l.get_data_ch11(batch_size=10)
train_momentum(0.02, 0.5)

Когда мы увеличиваем гиперпараметр импульса momentum до 0.9, эффективное число выборок становится равным 1−0.91​=10. Чтобы сохранить процесс управляемым, мы немного уменьшаем скорость обучения до 0.01.

train_momentum(0.01, 0.9)

Дополнительное снижение скорости обучения помогает справиться с трудностями, которые возникают при негладкой оптимизации. Если установить её равной 0.005, сходимость станет хорошей.

train_momentum(0.005, 0.9)

11.6.2.2 Краткая реализация

11.6.3 Теоретический анализ

Пример с 2D-функцией f(x)=0.1x12​+2x22​ может показаться надуманным. Ниже мы увидим, что он довольно типичен для реальных задач, по крайней мере при минимизации выпуклых квадратичных целевых функций.

11.6.3.1 Выпуклые квадратичные функции

Рассмотрим функцию

h(x)=21​x⊤Qx+x⊤c+b.

Это обычная квадратичная функция. Для положительно определённой матрицы Q≻0, то есть для матрицы с положительными собственными значениями, минимизатор равен x∗=−Q−1c, а минимальное значение — b−21​c⊤Q−1c. Поэтому можно переписать h в виде

h(x)=21​(x−Q−1c)⊤Q(x−Q−1c)+b−21​c⊤Q−1c.

Градиент задаётся формулой ∂x​f(x)=Q(x−Q−1c). То есть он равен расстоянию между x и минимизатором, умноженному на Q. Поэтому и обновление импульса представляет собой линейную комбинацию членов Q(xt​−Q−1c).

Поскольку Q положительно определена, её можно разложить как Q=O⊤ΛO, где O — ортогональная (поворотная) матрица, а Λ — диагональная матрица с положительными собственными значениями. Это позволяет перейти от переменной x к переменной z:=O(x−Q−1c) и получить очень простое выражение:

h(z)=21​z⊤Λz+b′.

Здесь b′=b−21​c⊤Q−1c. Поскольку O — всего лишь ортогональная матрица, она не искажает градиент по существу. Градиентный спуск в координатах z принимает вид

zt​=zt−1​−Λzt−1​=(I−Λ)zt−1​.

Важный факт, который следует из этого выражения, состоит в том, что градиентный спуск не смешивает различные собственные подпространства. То есть если работать в собственной системе Q, задача оптимизации решается покоординатно. Это справедливо и для метода импульса:

vt​zt​​=βvt−1​+Λzt−1​=zt−1​−η(βvt−1​+Λzt−1​)=(I−ηΛ)zt−1​−ηβvt−1​.​

Таким образом, мы доказали следующее: градиентный спуск с импульсом для невыпуклой квадратичной функции можно разложить на покоординатную оптимизацию вдоль собственных векторов квадратичной матрицы.

11.6.3.2 Скалярная функция

С учётом полученного результата рассмотрим, что происходит при минимизации функции f(x)=2λ​x2. Для градиентного спуска имеем

xt+1​=xt​−ηλxt​=(1−ηλ)xt​.

При ∣1−ηλ∣<1 эта оптимизация сходится с экспоненциальной скоростью, поскольку после t шагов получаем xt​=(1−ηλ)tx0​. Это показывает, как сначала растёт скорость сходимости по мере увеличения скорости обучения η до значения, при котором ηλ=1. За этим значением градиент начинает расходиться, а при ηλ>2 оптимизация расходится.

lambdas = [0.1, 1, 10, 19]
eta = 0.1
d2l.set_figsize((6, 4))
for lam in lambdas:
    t = d2l.numpy(d2l.arange(20))
    d2l.plt.plot(t, (1 - eta * lam) ** t, label=f'λ = {lam:.2f}')
d2l.plt.xlabel('время')
d2l.plt.legend();

Чтобы проанализировать сходимость метода импульса, сначала перепишем уравнения обновления через два скалярных значения: одно для x и одно для импульса v. Получаем:

[vt+1​xt+1​​]=[β−ηβ​λ(1−ηλ)​][vt​xt​​]=R(β,η,λ)[vt​xt​​].

Матрицей R обозначим 2×2 матрицу, которая определяет поведение сходимости. После t шагов начальные значения [v0​,x0​] становятся равными R(β,η,λ)t[v0​,x0​]. Поэтому скорость сходимости определяется собственными значениями R. Прекрасную анимацию можно найти в статье (Goh, 2017). Подробный анализ приведён в работе (Flammarion and Bach, 2015). Вкратце, метод импульса сходится при 0<ηλ<2+2β. Это более широкий диапазон допустимых параметров по сравнению с 0<ηλ<2 для градиентного спуска. Кроме того, в целом предпочтительны большие значения β.

Резюме

  • Метод импульса заменяет градиент средним значением прошлых градиентов, что существенно ускоряет сходимость.
  • Метод импульса полезен как для градиентного спуска без шума, так и для стохастического градиентного спуска с шумом.
  • Метод импульса может предотвратить застревание оптимизации в процессе стохастического градиентного спуска.
  • Из-за экспоненциального затухания весов прошлых данных эффективное число градиентов равно 1−β1​.
  • Для выпуклых квадратичных задач метод импульса допускает явный и подробный анализ.
  • Реализация метода импульса очень проста, но требует хранения дополнительного вектора состояния (импульса v).
