13.10 Транспонированная свёртка

Слои свёрточных нейронных сетей, которые мы рассматривали до сих пор, например свёрточные слои (раздел 6.2) и слои пулинга (раздел 6.5), обычно уменьшают пространственные размеры (высоту и ширину) входного изображения. Однако при семантической сегментации, где классификация выполняется на уровне пикселей, удобно, когда размеры входа и выхода совпадают. Например, канал выхода в каждой позиции может содержать результат классификации входного пикселя в той же позиции.

Чтобы этого добиться, особенно после того как пространственные размеры уменьшены слоями свёрточной сети, можно использовать другой тип слоя, который увеличивает пространственные размеры промежуточных карт признаков. В этом разделе мы рассмотрим транспонированную свёртку (transposed convolution) (Dumoulin and Visin, 2016), которая обращает уменьшение пространственных размеров, вызванное понижающей дискретизацией (downsampling).

MXNet:

from mxnet import np, npx, init
from mxnet.gluon import nn
from d2l import mxnet as d2l

npx.set_np()

PyTorch:

import torch
from torch import nn
from d2l import torch as d2l

PaddlePaddle:

from d2l import paddle as d2l
import paddle
from paddle import nn

13.10.1 Базовая операция

Временно игнорируем каналы и начнём с базовой транспонированной свёртки с шагом 1 и без заполнения. Пусть есть входной тензор размера nh​×nw​ и ядро свёртки размера kh​×kw​. Сдвигая окно ядра с шагом 1, nw​ раз в каждой строке и nh​ раз в каждом столбце, мы получаем nh​nw​ промежуточных результатов. Каждый промежуточный результат — тензор размера (nh​+kh​−1)×(nw​+kw​−1), изначально заполненный нулями. Чтобы вычислить каждый промежуточный тензор, каждый элемент входного тензора умножается на ядро, и полученный тензор kh​×kw​ записывается в соответствующую часть промежуточного тензора. Заметим, что положение этой части в промежуточном тензоре соответствует положению элемента во входном тензоре. Наконец, все промежуточные результаты складываются, и получается итоговый результат.

Например, на рис. 13.10.1 показано, как вычислить транспонированную свёртку с ядром 2×2 для входного тензора 2×2.

Рис. 13.10.1. Транспонированная свёртка с ядром 2×2. Затенённые части — часть промежуточного тензора, а также элементы входного тензора и ядра, использованные в вычислении

Выполним базовую операцию транспонированной свёртки для входной матрицы X и матрицы ядра K с помощью функции trans_conv.

def trans_conv(X, K):
    h, w = K.shape
    Y = d2l.zeros((X.shape[0] + h - 1, X.shape[1] + w - 1))
    for i in range(X.shape[0]):
        for j in range(X.shape[1]):
            Y[i: i + h, j: j + w] += X[i, j] * K
    return Y

В отличие от обычной свёртки, которая «уменьшает» входные элементы с помощью ядра (раздел 6.2), транспонированная свёртка «распространяет» входные элементы с помощью ядра и тем самым даёт выход больше входа. Мы можем проверить вывод этой реализации, построив входной тензор X и тензор ядра K как на рис. 13.10.1. Эта реализация — базовая двумерная транспонированная свёртка.

X = d2l.tensor([[0.0, 1.0], [2.0, 3.0]])
K = d2l.tensor([[0.0, 1.0], [2.0, 3.0]])
trans_conv(X, K)

Кроме того, если входной тензор X и ядро K — четырёхмерные тензоры, можно получить тот же результат с помощью высокоуровневого API.

MXNet:

X, K = X.reshape(1, 1, 2, 2), K.reshape(1, 1, 2, 2)
tconv = nn.Conv2DTranspose(1, kernel_size=2)
tconv.initialize(init.Constant(K))
tconv(X)

PyTorch:

X, K = X.reshape(1, 1, 2, 2), K.reshape(1, 1, 2, 2)
tconv = nn.ConvTranspose2d(1, 1, kernel_size=2, bias=False)
tconv.weight.data = K
tconv(X)

PaddlePaddle:

X, K = X.reshape([1, 1, 2, 2]), K.reshape([1, 1, 2, 2])
tconv = nn.Conv2DTranspose(1, 1, kernel_size=2, bias_attr=False)
K = paddle.create_parameter(shape=K.shape, dtype="float32", 
        default_initializer=paddle.nn.initializer.Assign(K))
tconv.weight = K
tconv(X)

13.10.2 Заполнение, шаг и многоканальность

В отличие от обычной свёртки, в транспонированной свёртке заполнение применяется к выходу (в обычной свёртке — к входу). Например, если задать заполнение по высоте и ширине равным 1, то первая и последняя строки и столбцы выхода транспонированной свёртки удаляются.

MXNet:

tconv = nn.Conv2DTranspose(1, kernel_size=2, padding=1)
tconv.initialize(init.Constant(K))
tconv(X)

PyTorch:

tconv = nn.ConvTranspose2d(1, 1, kernel_size=2, padding=1, bias=False)
tconv.weight.data = K
tconv(X)

PaddlePaddle:

tconv = nn.Conv2DTranspose(1, 1, kernel_size=2, padding=1, bias_attr=False)
tconv.weight = K
tconv(X)

В транспонированной свёртке шаг задаётся для промежуточного результата (выхода), а не для входа. Используем те же входной тензор и тензор ядра, что и на рис. 13.10.1, и изменим шаг с 1 на 2. Это увеличивает высоту и ширину промежуточного тензора, а выходной тензор показан на рис. 13.10.2.

Рис. 13.10.2. Транспонированная свёртка с ядром 2×2 и шагом 2. Затенённые части — часть промежуточного тензора, а также элементы входного тензора и ядра, использованные в вычислении

Следующий код проверяет выход транспонированной свёртки с шагом 2 из рис. 13.10.2.

MXNet:

tconv = nn.Conv2DTranspose(1, kernel_size=2, strides=2)
tconv.initialize(init.Constant(K))
tconv(X)

PyTorch:

tconv = nn.ConvTranspose2d(1, 1, kernel_size=2, stride=2, bias=False)
tconv.weight.data = K
tconv(X)

PaddlePaddle:

tconv = nn.Conv2DTranspose(1, 1, kernel_size=2, stride=2, bias_attr=False)
tconv.weight = K
tconv(X)

Для нескольких входных и выходных каналов транспонированная свёртка работает так же, как обычная. Пусть вход имеет ci​ каналов, и транспонированная свёртка назначает каждому входному каналу тензор ядра kh​×kw​. Если задано несколько выходных каналов, то для каждого выходного канала будет ядро размера ci​×kh​×kw​.

Аналогично, если подать X на вход свёрточного слоя f, получить выход Y=f(X) и создать транспонированный свёрточный слой g с теми же гиперпараметрами, но с числом выходных каналов, равным числу каналов в X, то форма g(Y) совпадёт с формой X. Следующий пример это иллюстрирует.

MXNet:

X = np.random.uniform(size=(1, 10, 16, 16))
conv = nn.Conv2D(20, kernel_size=5, padding=2, strides=3)
tconv = nn.Conv2DTranspose(10, kernel_size=5, padding=2, strides=3)
conv.initialize()
tconv.initialize()
tconv(conv(X)).shape == X.shape

PyTorch:

X = torch.rand(size=(1, 10, 16, 16))
conv = nn.Conv2d(10, 20, kernel_size=5, padding=2, stride=3)
tconv = nn.ConvTranspose2d(20, 10, kernel_size=5, padding=2, stride=3)
tconv(conv(X)).shape == X.shape

PaddlePaddle:

X = paddle.rand(shape=(1, 10, 16, 16))
conv = nn.Conv2D(10, 20, kernel_size=5, padding=2, stride=3)
tconv = nn.Conv2DTranspose(20, 10, kernel_size=5, padding=2, stride=3)
tconv(conv(X)).shape == X.shape

13.10.3 Связь с матричным транспонированием

Почему транспонированная свёртка получила название от матричного транспонирования? Сначала посмотрим, как реализовать свёртку с помощью матричного умножения. В приведённом ниже примере мы задаём входной тензор X размера 3×3 и ядро K размера 2×2, а затем с помощью функции corr2d вычисляем выход свёртки Y.

MXNet, PyTorch:

X = d2l.arange(9.0).reshape(3, 3)
K = d2l.tensor([[1.0, 2.0], [3.0, 4.0]])
Y = d2l.corr2d(X, K)
Y

PaddlePaddle:

X = d2l.arange(9.0, dtype="float32").reshape((3, 3))
K = d2l.tensor([[1.0, 2.0], [3.0, 4.0]])
Y = d2l.corr2d(X, K)
Y

Далее перепишем ядро K в виде разреженной весовой матрицы W, в которой много нулей. Форма весовой матрицы равна (4, 9), а ненулевые элементы берутся из ядра K.

MXNet, PyTorch:

def kernel2matrix(K):
    k, W = d2l.zeros(5), d2l.zeros((4, 9))
    k[:2], k[3:5] = K[0, :], K[1, :]
    W[0, :5], W[1, 1:6], W[2, 3:8], W[3, 4:] = k, k, k, k
    return W

W = kernel2matrix(K)
W

PaddlePaddle:

def kernel2matrix(K):
    k, W = d2l.zeros([5]), d2l.zeros((4, 9))
    k[:2], k[3:5] = K[0, :], K[1, :]
    W[0, :5], W[1, 1:6], W[2, 3:8], W[3, 4:] = k, k, k, k
    return W

W = kernel2matrix(K)
W

Входной тензор X построчно преобразуется в вектор длины 9. Затем умножение матрицы W на векторизованный X даёт вектор длины 4. После изменения его формы получается тот же результат Y, что и при исходной свёртке: мы только что реализовали свёртку с помощью матричного умножения.

MXNet, PyTorch:

Y == d2l.matmul(W, d2l.reshape(X, -1)).reshape(2, 2)

PaddlePaddle:

Y == d2l.matmul(W, d2l.reshape(X, [-1])).reshape((2, 2))

Аналогично можно реализовать транспонированную свёртку с помощью матричного умножения. В следующем примере мы берём выход Y обычной свёртки 2×2 выше в качестве входа транспонированной свёртки. Чтобы реализовать её матричным умножением, достаточно транспонировать матрицу весов W до формы (9, 4).

MXNet, PyTorch:

Z = trans_conv(Y, K)
Z == d2l.matmul(W.T, d2l.reshape(Y, -1)).reshape(3, 3)

PaddlePaddle:

Z = trans_conv(Y, K)
Z == d2l.matmul(W.T, d2l.reshape(Y, [-1])).reshape((3, 3))

В общем виде, для входного вектора x и матрицы весов W прямое распространение свёртки можно реализовать как умножение входа на матрицу весов, выдающее вектор y=Wx. Поскольку обратное распространение следует правилу цепочки и ∇x​y=W⊤, обратное распространение свёртки можно реализовать как умножение входа на транспонированную матрицу весов W⊤. Поэтому транспонированный свёрточный слой может поменять местами прямое и обратное распространение обычного свёрточного слоя: его прямое и обратное распространение умножают входной вектор на W⊤ и W соответственно.

Резюме

  • В отличие от обычной свёртки, которая уменьшает входные элементы с помощью ядра, транспонированная свёртка распространяет входные элементы с помощью ядра и тем самым даёт выход, форма которого больше формы входа.
  • Если подать X на вход свёрточного слоя f, получить выход Y=f(X) и создать транспонированный свёрточный слой g с теми же гиперпараметрами, но с числом выходных каналов, равным числу каналов в X, то форма g(Y) совпадёт с формой X.
  • Свёртку можно реализовать с помощью матричного умножения. Транспонированный свёрточный слой может поменять местами прямое и обратное распространение обычного свёрточного слоя.
