8.5.1 One-hot кодирование

Напомним, что в train_iter каждый токен представлен числовым индексом. Если подавать такие индексы напрямую в нейронную сеть, обучение может быть затруднено. Поэтому обычно каждый токен представляют более выразительным вектором признаков. Самое простое представление называется one-hot кодированием (one-hot encoding); оно было введено в разделе 3.4.1.

Коротко говоря, каждый индекс отображается в свой единичный вектор. Пусть число различных токенов в словаре равно N (то есть len(vocab)), а индексы токенов принимают значения от 0 до N−1. Если индекс токена равен целому числу i, мы создаём вектор длины N, заполненный нулями, и устанавливаем его элемент с индексом i равным 1. Полученный вектор — one-hot вектор исходного токена. Ниже показаны one-hot векторы для индексов 0 и 2:

MXNet:

npx.one_hot(np.array([0, 2]), len(vocab))

PyTorch:

F.one_hot(torch.tensor([0, 2]), len(vocab))

TensorFlow:

tf.one_hot(tf.constant([0, 2]), len(vocab))

PaddlePaddle:

F.one_hot(paddle.to_tensor([0, 2]), len(vocab))

Каждый выбранный минибатч имеет форму двумерного тензора: (размер батча, число временных шагов). Функция one_hot превращает такой минибатч в трёхмерный тензор, последняя размерность которого равна размеру словаря (len(vocab)). Мы часто переставляем оси входа, чтобы получить выход формы (число временных шагов, размер батча, размер словаря). Это позволяет удобно перебирать минибатч по самой внешней оси и шаг за шагом обновлять скрытое состояние минибатча.

8.5.2 Инициализация параметров модели

Теперь инициализируем параметры модели рекуррентной нейронной сети. Число скрытых элементов num_hiddens — настраиваемый гиперпараметр. При обучении языковой модели входы и выходы берутся из одного и того же словаря. Поэтому их размерности совпадают и равны размеру словаря.

MXNet:

def get_params(vocab_size, num_hiddens, device):
    num_inputs = num_outputs = vocab_size

    def normal(shape):
        return np.random.normal(scale=0.01, size=shape, ctx=device)

    # Параметры скрытого слоя
    W_xh = normal((num_inputs, num_hiddens))
    W_hh = normal((num_hiddens, num_hiddens))
    b_h = d2l.zeros(num_hiddens, ctx=device)
    # Параметры выходного слоя
    W_hq = normal((num_hiddens, num_outputs))
    b_q = d2l.zeros(num_outputs, ctx=device)
    # Включаем вычисление градиентов
    params = [W_xh, W_hh, b_h, W_hq, b_q]
    for param in params:
        param.attach_grad()
    return params

8.5.3 Модель рекуррентной нейронной сети

Чтобы определить модель рекуррентной нейронной сети, сначала нужна функция init_rnn_state, которая возвращает скрытое состояние при инициализации. Эта функция возвращает тензор, заполненный нулями, формы (размер батча, число скрытых элементов). В следующих главах мы встретимся с ситуациями, когда скрытое состояние содержит несколько переменных; их удобнее хранить в кортеже.

MXNet:

def init_rnn_state(batch_size, num_hiddens, device):
    return (d2l.zeros((batch_size, num_hiddens), ctx=device), )

PyTorch:

def init_rnn_state(batch_size, num_hiddens, device):
    return (d2l.zeros((batch_size, num_hiddens), device=device), )

TensorFlow:

def init_rnn_state(batch_size, num_hiddens):
    return (d2l.zeros((batch_size, num_hiddens)), )

PaddlePaddle:

def init_rnn_state(batch_size, num_hiddens):
    return (paddle.zeros(shape=[batch_size, num_hiddens]), )

Функция rnn ниже определяет, как вычислить скрытое состояние и выход на одном временном шаге. Модель рекуррентной нейронной сети реализует цикл по самой внешней оси inputs, чтобы последовательно обновлять скрытое состояние H минибатча. Кроме того, здесь в качестве функции активации используется tanh. Как описано в разделе 4.1, при равномерном распределении элементов на вещественной оси среднее значение функции tanh равно 0.

MXNet:

def rnn(inputs, state, params):
    # Форма inputs: (число временных шагов, размер батча, размер словаря)
    W_xh, W_hh, b_h, W_hq, b_q = params
    H, = state
    outputs = []
    # Форма X: (размер батча, размер словаря)
    for X in inputs:
        H = np.tanh(np.dot(X, W_xh) + np.dot(H, W_hh) + b_h)
        Y = np.dot(H, W_hq) + b_q
        outputs.append(Y)
    return np.concatenate(outputs, axis=0), (H,)

PyTorch:

def rnn(inputs, state, params):
    # Форма inputs: (число временных шагов, размер батча, размер словаря)
    W_xh, W_hh, b_h, W_hq, b_q = params
    H, = state
    outputs = []
    # Форма X: (размер батча, размер словаря)
    for X in inputs:
        H = torch.tanh(torch.mm(X, W_xh) + torch.mm(H, W_hh) + b_h)
        Y = torch.mm(H, W_hq) + b_q
        outputs.append(Y)

Определив все нужные функции, создадим класс, который объединяет эти функции и хранит параметры модели рекуррентной нейронной сети, реализованной с нуля.

class RNNModelScratch:  #@save
    """Модель рекуррентной нейронной сети, реализованная с нуля"""
    def __init__(self, vocab_size, num_hiddens, device, get_params,
                 init_state, forward_fn):
        self.vocab_size, self.num_hiddens = vocab_size, num_hiddens
        self.params = get_params(vocab_size, num_hiddens, device)
        self.init_state, self.forward_fn = init_state, forward_fn

8.5.4 Предсказание

Сначала определим функцию предсказания, которая генерирует новые символы после prefix; prefix — это строка из нескольких символов, которую задаёт пользователь. При проходе по начальным символам prefix мы продолжаем передавать скрытое состояние на следующий временной шаг, но ничего не выводим. Это называется периодом разогрева (warm-up), потому что в этот период модель обновляет себя (например, обновляет скрытое состояние), но предсказаний не делает. После периода разогрева скрытое состояние обычно лучше подходит для предсказаний, чем исходное, и тогда модель начинает предсказывать символы и выводить их.

MXNet:

def predict_ch8(prefix, num_preds, net, vocab, device):  #@save
    """Генерирует новые символы после prefix"""
    state = net.begin_state(batch_size=1, ctx=device)
    outputs = [vocab[prefix[0]]]
    get_input = lambda: d2l.reshape(
        d2l.tensor([outputs[-1]], ctx=device), (1, 1))
    for y in prefix[1:]:  # Период разогрева
        _, state = net(get_input(), state)
        outputs.append(vocab[y])
    for _ in range(num_preds):  # Предсказываем num_preds шагов
        y, state = net(get_input(), state)
        outputs.append(int(y.argmax(axis=1).reshape(1)))
    return ''.join([vocab.idx_to_token[i] for i in outputs])

8.5.5 Отсечение градиентов

Для последовательности длины T мы вычисляем градиенты на всех T временных шагах; при обратном распространении возникает цепочка матричных умножений длины O(T). Как описано в разделе 4.8, при большом T это может привести к численной неустойчивости, например к взрыву или затуханию градиентов. Поэтому модели рекуррентных сетей часто требуют дополнительных приёмов, которые помогают стабилизировать обучение.

В общем случае при решении задачи оптимизации мы обновляем параметры модели. Пусть x — вектор параметров, а g — градиент для минибатча, взятый с отрицательным знаком. Если скорость обучения равна η>0, то за одну итерацию x обновляется до x−ηg. Допустим дополнительно, что целевая функция f хорошо себя ведёт: она липшицево непрерывна с постоянной L (Lipschitz continuous). То есть для любых x и y выполнено:

∣f(x)−f(y)∣≤L∥x−y∥.

В этом случае можно уверенно утверждать, что если обновить вектор параметров на ηg, то

∣f(x)−f(x−ηg)∣≤Lη∥g∥,

то есть значение функции не изменится больше чем на Lη∥g∥. Это одновременно и плохо, и хорошо. Плохо, что такая оценка ограничивает скорость продвижения; хорошо, что она ограничивает масштаб ухудшения, особенно когда мы движемся в неверном направлении.

Иногда градиенты могут быть очень большими, и тогда алгоритм оптимизации может не сойтись. Можно решить эту проблему, уменьшив скорость обучения η. Но что делать, если большие градиенты встречаются редко? Тогда уменьшать скорость обучения не имеет смысла. Распространённая альтернатива — отсечь градиент g, спроецировав его обратно на шар заданного радиуса θ:

g←min(1,∥g∥θ​)g.

Так мы гарантируем, что норма градиента никогда не превысит θ, а обновлённый градиент будет точно сонаправлен с исходным g. Есть и полезный побочный эффект: отсечение ограничивает влияние любого отдельного минибатча (и любого отдельного примера в нём) на вектор параметров, что придаёт модели определённую устойчивость. Отсечение градиентов — быстрый способ справиться со взрывом градиентов; оно не решает проблему полностью, но входит в число эффективных приёмов.

Ниже мы определяем функцию, которая отсекает градиенты модели; модель может быть реализована с нуля или построена с помощью высокоуровневого API. Мы вычисляем норму градиентов по всем параметрам модели.

MXNet:

def grad_clipping(net, theta):  #@save
    """Отсечение градиентов"""
    if isinstance(net, gluon.Block):
        params = [p.data() for p in net.collect_params().values()]
    else:
        params = net.params
    norm = math.sqrt(sum((p.grad ** 2).sum() for p in params))
    if norm > theta:
        for param in params:
            param.grad[:] *= theta / norm

PyTorch:

def grad_clipping(net, theta):  #@save

    if isinstance(net, nn.Module):
        params = [p for p in net.parameters() if p.requires_grad]

TensorFlow:

def grad_clipping(grads, theta):  #@save
    """Отсечение градиентов"""
    theta = tf.constant(theta, dtype=tf.float32)
    new_grad = []
    for grad in grads:
        if isinstance(grad, tf.IndexedSlices):
            new_grad.append(tf.convert_to_tensor(grad))
        else:
            new_grad.append(grad)
    norm = tf.math.sqrt(sum((tf.reduce_sum(grad ** 2)).numpy()
                        for grad in new_grad))
    norm = tf.cast(norm, tf.float32)
    if tf.greater(norm, theta):
        for i, grad in enumerate(new_grad):
            new_grad[i] = grad * theta / norm
    else:
        new_grad = new_grad
    return new_grad

PaddlePaddle:

def grad_clipping(net, theta):  #@save
    """Отсечение градиентов"""
    if isinstance(net, nn.Layer):
        params = [p for p in net.parameters() if not p.stop_gradient]
    else:
        params = net.params
    norm = paddle.sqrt(sum(paddle.sum((p.grad ** 2)) for p in params))
    if norm > theta:
        with paddle.no_grad():
            for param in params:
                param.grad.set_value(param.grad * theta / norm)

8.5.6 Обучение

Прежде чем обучать модель, определим функцию, которая обучает модель в течение одной эпохи. Она отличается от функции обучения модели из раздела 3.6 тремя моментами.

  1. Разные способы выборки последовательных данных (случайная выборка и последовательное разбиение) приводят к разной инициализации скрытого состояния.
  2. Мы отсекаем градиенты перед обновлением параметров модели. Это гарантирует, что даже если в какой-то точке обучения произошёл взрыв градиента, модель не расходится.
  3. Модель оцениваем по перплексии, как описано в разделе 8.4.4. Такая мера гарантирует, что последовательности разной длины можно сравнивать.

Конкретно, при последовательном разбиении мы инициализируем скрытое состояние только в начале каждой эпохи. Поскольку i-й пример следующего минибатча является соседним с i-м примером текущего минибатча, скрытое состояние, полученное в последнем примере текущего минибатча, используется для инициализации скрытого состояния первого примера следующего минибатча. Так информация об истории последовательности, сохранённая в скрытом состоянии, может передаваться между соседними подпоследовательностями в пределах одной эпохи. Однако вычисление скрытого состояния в любой точке зависит от всех предыдущих минибатчей той же эпохи, и это усложняет вычисление градиентов. Чтобы уменьшить объём вычислений, перед обработкой каждого минибатча мы отсоединяем (detach) скрытое состояние от графа вычислений, так что вычисление градиента скрытого состояния ограничено временными шагами одного минибатча.

При случайной выборке каждый пример берётся из случайной позиции, поэтому скрытое состояние нужно переинициализировать для каждой эпохи. Так же, как функция train_epoch_ch3 из раздела 3.6, updater — это общая функция обновления параметров модели. Это может быть функция d2l.sgd, реализованная с нуля, или встроенная оптимизационная функция фреймворка глубокого обучения.

MXNet:

#@save
def train_epoch_ch8(net, train_iter, loss, updater, device, use_random_iter):
    """Обучает модель в течение одной эпохи (определение см. в главе 8)"""
    state, timer = None, d2l.Timer()
    metric = d2l.Accumulator(2)  # Сумма потерь на обучении, количество токенов
    for X, Y in train_iter:
        if state is None or use_random_iter:
            # Инициализируем state на первой итерации или при случайной выборке
            state = net.begin_state(batch_size=X.shape[0], ctx=device)
        else:
            for s in state:
                s.detach()
        y = Y.T.reshape(-1)
        X, y = X.as_in_ctx(device), y.as_in_ctx(device)
        with autograd.record():
            y_hat, state = net(X, state)
            l = loss(y_hat, y).mean()
        l.backward()
        grad_clipping(net, 1)
        updater(batch_size=1)  # Поскольку функция mean уже вызвана
        metric.add(l * d2l.size(y), d2l.size(y))
    return math.exp(metric[0] / metric[1]), metric[1] / timer.stop()

def train_epoch_ch8(net, train_iter, loss, updater, use_random_iter):

Резюме

  • Мы можем обучить символьную языковую модель на основе рекуррентной нейронной сети, которая генерирует продолжение текста по заданному пользователем префиксу.
  • Простая языковая модель на основе рекуррентной нейронной сети состоит из кодирования входа, рекуррентной нейронной сети и генерации выхода.
  • Перед обучением модели рекуррентной нейронной сети нужно инициализировать её состояние, причём при случайной выборке и последовательном разбиении используются разные способы инициализации.
  • При последовательном разбиении нужно отделять градиенты, чтобы сократить объём вычислений.
  • Перед любыми предсказаниями модель обновляет себя в период разогрева (например, получает скрытое состояние лучше начального).
  • Отсечение градиентов помогает предотвратить взрыв градиентов, но не справляется с затуханием градиентов.

    • Как будет работать модель, если в качестве набора данных взять другую книгу Герберта Уэллса, например «Война миров»?
  3. Измените функцию предсказания так, чтобы вместо выбора наиболее вероятного следующего символа использовалась выборка.
