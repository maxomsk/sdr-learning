Курсы для радиоинженеров — фокус SDR / RF

Подборка для инженеров, которым нужна практическая база по программно-определяемому радио (SDR), радиочастотной технике и цифровой обработке сигналов. Акцент — на курсах и материалах, дающих работающие навыки, а не только теорию. Языки: русский и английский. Обновлено: 2026-10-19.

Пометки: 🟢 бесплатно · 🟡 бесплатно с платным сертификатом/продлением · 🔵 платно.

Рекомендуемый маршрут

  1. Сигналы и системы — MIT 6.003 (или Баскаков) — фундамент для всего дальнейшего.
  2. ЦОС — MIT 6.341 + практика: online.edu.ru / Stepik / Python (NumPy/SciPy).
  3. ЭМ и СВЧ — MIT 6.013 + Pozar; при интересе к схемам — Razavi.
  4. SDR-практика — PySDR → GNU Radio → железо (Pluto/HackRF/USRP).
  5. Прикладное — антенны (Balanis), измерения (ARRL/Keysight), при необходимости радар.

Короткий путь до первого SDR-проекта: MIT 6.003 → PySDR → GNU Radio + Pluto/HackRF.
