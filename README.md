# sdr-learning

Учебные материалы по ИИ и машинному обучению для инженеров-программистов,
с отдельным уклоном в **МЛ для радио / SDR / сигналов (RFML)** — в русле задач
по программно-определяемому радио и анализу радиоэфира.

## Содержание

| Файл / каталог | Что это |
|---|---|
| [`ОБУЧЕНИЕ_ИИ_МЛ.md`](ОБУЧЕНИЕ_ИИ_МЛ.md) | Подборка курсов и материалов (Markdown) |
| [`ОБУЧЕНИЕ_ИИ_МЛ.html`](ОБУЧЕНИЕ_ИИ_МЛ.html) | То же в виде автономной HTML-страницы (light/dark) |
| [`DiveIntoDeepLearning/`](DiveIntoDeepLearning/) | Учебник «Погружение в глубокое обучение» (D2L) |

Подборка охватывает: математический фундамент, классический ML, глубокое обучение,
русскоязычные курсы, RFML (PySDR, TorchSig, RadioML, Sionna) и практику.
В конце — рекомендуемый маршрут из двух треков (общий ML/DL и RFML).
